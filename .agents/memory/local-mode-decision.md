---
name: SquadCraft local mode
description: Default storage and preview behavior when Supabase is not configured.
---

Quand Supabase n’est pas configuré, SquadCraft doit rester utilisable en mode local avec des comptes de démonstration et une persistance dans le stockage du navigateur.

**Why:** L’objectif prioritaire est de permettre la validation visuelle et l’utilisation immédiate sans bloquer l’application sur des identifiants externes.

**How to apply:** Conserver un parcours d’aperçu direct, un compte CP de démonstration et des données locales réalistes ; présenter Supabase comme une option pour synchroniser plusieurs appareils.
