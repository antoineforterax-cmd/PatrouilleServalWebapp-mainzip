---
name: SquadCraft local mode
description: Default storage and preview behavior when Supabase is not configured.
---

Quand Supabase n’est pas configuré, SquadCraft doit rester utilisable en mode local avec une première installation vide et une persistance dans le stockage du navigateur.

**Why:** L’objectif prioritaire est de permettre la validation visuelle et l’utilisation immédiate sans bloquer l’application sur des identifiants externes, tout en laissant le responsable créer ses propres comptes.

**How to apply:** Conserver un parcours de première installation vide où le CP crée son propre accès, puis présente Supabase comme une option pour synchroniser plusieurs appareils.
